# Currency Converter (Fetch API)

Convert currencies in real time using Fetch API and free exchange rate data.

---

## Overview
This project demonstrates how to use the Fetch API to retrieve live exchange rates and perform currency conversions. It is designed as a simple, lightweight tool for students and developers learning modern JavaScript.

---

## Features
- Real-time currency conversion
- Clean and responsive UI
- Built with JavaScript (Fetch API)
- Supports multiple currencies
